# ChatGPT Reel — «اتعلم تستخدم ChatGPT باحتراف!»

ريل موشن جرافيك تعليمي **60 ثانية**، **1080×1920 (9:16)** لـ Reels وTikTok، **30fps**، بالعربي المصري. كل الحركة مكتوبة بالكود (Remotion + React + TypeScript) ومحسوبة بالفريمات.

## الملفات (`out/`)

| الملف | الوصف |
| --- | --- |
| `out/chatgpt-reel.mp4` | الريل النهائي: الصورة + الكابشن + الموسيقى + المؤثرات |
| `out/captions.srt` | ملف الكابشن العربي |

> **التعليق الصوتي مش موجود في النسخة دي** — رصيد ElevenLabs خلص. الكابشن متوقّت مع المشاهد من `script.json` بحيث يتقري كنص على الشاشة. لما يبقى عندك تسجيل، شوف «إضافة تعليق صوتي» تحت.

## التشغيل

```bash
npm install
npm run dev           # معاينة في Remotion Studio
npm run render        # تصدير الريل out/chatgpt-reel.mp4
npm run render:clean  # بدون كابشن محروق
npm run render:4k     # 2160×3840 (بطيء جدًا على جهاز من غير GPU)
```

لو الجهاز مش بيقدر ينزّل Chrome Headless Shell: `REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render`.

## إضافة تعليق صوتي (تسجيلك أو أي أداة TTS)

1. سجّل النص الموجود في `src/config/script.json` بالظبط، مع وقفة قصيرة بين كل فقرة والتانية.
2. احفظ الملف في `public/audio/voiceover.mp3`.
3. شغّل `npm run sync` — بيقسّم التسجيل لفقرات عند الوقفات الطويلة ويوزّع الكلمات عليها (من غير أي خدمة خارجية). الموسيقى بتوطى تلقائيًا تحت الصوت.
4. لو فقرة أطول من مشهدها، عدّل `placeAt` بتاعها في `script.json` وشغّل `npm run captions`.
5. `npm run render`.

لتوقيت كلمة بكلمة دقيق: حط ناتج أي أداة تفريغ صوتي في `src/data/voiceover-words.raw.json` بالشكل `{"words":[{"text":"…","type":"word","start":0.0,"end":0.4}]}` وشغّل `npm run captions` بدل `sync`.

## الشعار الرسمي

الفيديو حاليًا بيعرض **شارة محايدة** (فقاعة شات خضرا + كلمة ChatGPT) بدل الشعار — مش تقليد ولا رسم للشعار. عشان تحط الشعار الرسمي:

1. نزّل ملف الشعار من صفحة الهوية الرسمية لـ OpenAI واحفظه في `public/brand/chatgpt-logo.svg`.
2. في `src/config/brand.ts` خلّي `OFFICIAL_LOGO: "brand/chatgpt-logo.svg"` (و`LOGO_TINT` حسب لون الملف).
3. `npm run render`.

الشعار ملك OpenAI؛ اتبع إرشادات استخدام العلامة التجارية بتاعتهم. سطر «فيديو تعليمي غير رسمي» في الخاتمة بيتغيّر أو يتشال من `DISCLAIMER` في نفس الملف.

## هيكل المشروع

```
src/
  Main.tsx                  ترتيب المشاهد + الانتقالات + الكابشن + الصوت
  Overlay.tsx               كابشن + صوت على خلفية شفافة (للتركيب بدون إعادة رندر)
  config/
    theme.ts                🎨 الألوان (أخضر / أبيض / أسود / رمادي) والخطوط
    timeline.ts             ⏱️ بداية ونهاية كل مشهد
    copy.ts                 ✍️ كل النصوص على الشاشة
    brand.ts                🟢 الشعار + سطر التنويه
    script.json             🎙️ نص التعليق وتوقيته والكلمات الملوّنة في الكابشن
    sfx.ts                  🔊 جدول المؤثرات
  scenes/
    Scene01Hook.tsx         خطوط ضوء ← الشعار 3D ← انفجار ضوئي ← العنوان
    Scene02Intro.tsx        موبايل 3D ← تسجيل الدخول ← واجهة الشات ← مربع الكتابة
    Scene03Prompt.tsx       طلب ضعيف vs طلب احترافي + مقارنة النتيجة
    Scene04Uses.tsx         6 استخدامات، كل أيقونة تتحول لمشهد مصغّر
    Scene05Advanced.tsx     رفع صورة وتحليلها ← محادثة صوتية ← ملفات ولوحة بيانات
    Scene06Outro.tsx        العناصر تتجمع حوالين الشعار ← العبارة الختامية ← Fade
  components/               واجهة الشات والموبايل، الكابشن، الجزيئات، الانتقالات
scripts/
  build-captions.mjs        يبني الكابشن + SRT
  align-voiceover.mjs       توقيت تسجيلك الصوتي offline
  generate-audio.mjs        يولّد الموسيقى والمؤثرات برمجيًا (120 BPM)
```

## عن دقة المحتوى

الواجهات مبنية على شكل تطبيق ChatGPT الحقيقي (مربع الكتابة، زر +، المايك، وضع الصوت، رفع الصور والملفات، إنشاء الصور، البحث، تحليل البيانات) لكنها رسومات توضيحية مش لقطات شاشة. المميزات المتاحة بتختلف حسب الخطة والجهاز، وده مكتوب في المشهد الخامس والخاتمة.
