# ريل «مهارات Claude» — Skills

ريل موشن جرافيك تعليمي **68.5 ثانية**، **1080×1920 (9:16)**، **30fps**، بالمصري، لـ YouTube Shorts / Reels.
كل الحركة مكتوبة بالكود (Remotion + React)، والموسيقى والمؤثرات متولّدة بسكريبت (مفيش ملفات صوت متنزّلة).

> **من غير تعليق صوتي:** رصيد ElevenLabs مكانش كفاية (176 من 772 credit). الكلام كله نص على الشاشة بإيقاع القراية.

## التشغيل

```bash
npm install
npm run studio   # معاينة
npm run render   # out/skills-reel.mp4 (بيولّد الصوت الأول، وبيظبط الصوت على -14 LUFS لليوتيوب)
npm run cover    # out/cover.png
npm run check -- 60 300 900   # صور مراجعة لفريمات معيّنة في out/check/
```

## المشاهد (`src/timeline.ts`)

| من | لـ | المشهد |

| 0 | 5.5 | الهوك: نفس الطلب بيتكرر ×6 ← «إنت بتضيّع وقتك» |
| 5.5 | 11.5 | الحل اسمه Skills |
| 11.5 | 24 | المهارة = فولدر + SKILL.md (اسم، وصف، تعليمات، ملفات مساعدة) |
| 24 | 35.5 | Claude بيشوف الوصف بس، ولما طلبك يناسبه يفتح المهارة |

| 47 | 54.5 | نصيحة 1: اقرا المهارة قبل ما تثبّتها (سطر حقيقي بيعمل pip install) |
| 54.5 | 62 | نصيحة 2: 270 مهارة على الحساب، اتمسح منهم 15 |
| 62 | 68.5 | الخاتمة |

## التعديل

- الألوان والخطوط والإيقاع: `src/theme.ts`
- التوقيت: `src/timeline.ts` — المؤثرات: `src/sfx.ts`
- الخطوط في `public/fonts/` (Readex Pro، IBM Plex Sans Arabic، JetBrains Mono — كلها OFL)

## إضافة تعليق صوتي بعدين

النص في `youtube.md`. سجّله أو ولّده، حطه في `public/audio/voiceover.mp3`، وضيف
`<Audio src={staticFile("audio/voiceover.mp3")} />` في `src/Main.tsx` ووطّي `volume` الموسيقى لـ 0.12.
