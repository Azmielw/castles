## 1. Brief
- **Concept:** a voiceless explainer reel: how to use Claude Code from the phone, in 5 steps, plus Remote Control, closing on "this video itself was made with Claude Code".
- **Format:** 9:16 1080×1920, 30 fps, 70.5 s, no narration (no ElevenLabs key, no recording yet).
- **Audience:** Arabic-speaking developers and curious people; on-screen text in light Egyptian dialect (the user writes Egyptian).
- **Structure:** hook (0–5) → no laptop (5–10) → 5 steps (10–55) with HUD pips → remote control (55–61) → proof (61–66) → end line (66–70.5).
- **Hook:** direct question «تبرمج من موبايلك؟» lit at frame 0 + a phone typing code (family: direct question / proof).
